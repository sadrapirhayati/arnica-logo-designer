# Arnica Logo Generator

A small, browser-only SVG logo editor. Open `index.html` locally; no build tools or server are required.

- **Live app:** https://sadrapirhayati.github.io/arnica-logo-designer/
- **Source repository:** https://github.com/sadrapirhayati/arnica-logo-designer

## Features

- Edit each ring independently, including radius, square count and size, corner radius, color, rotation, opacity, and visibility.
- Keep the square chord aligned with the circle while rotating a ring.
- Import and edit SVGs exported by the application. New exports embed their editor settings in SVG metadata.
- Preview a reference image, animate the rings, and export a standalone SVG.

## Publish with GitHub Pages

The public repository is configured to deploy from the `main` branch root. To publish updates, commit the updated `index.html` and `arnica-logo-generator.js` files to that branch. GitHub Pages will deploy the new version automatically.

## Run locally

Open `index.html` in a modern browser. All application files are served locally; no dependencies are required.
